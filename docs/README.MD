## Features
- **Neobrutalism UI**: Standout, bold, and highly interactive design.
- **Client Management**: Full CRUD operations for your client database.
- **Invoice Tracker**: Monitor invoice statuses (Draft, Sent, Paid, Overdue) in real-time.
- **1-Click PDF Export**: Generate professional, print-ready PDF invoices directly from the browser using `@react-pdf/renderer`.
- **Secure Authentication**: Powered by Supabase Auth with strict Row Level Security (RLS) to ensure user data isolation.
